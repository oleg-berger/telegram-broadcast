# Каталог получателей WhatsApp

Каталог MySQL хранит получателей отдельно от очереди SQLite. Таблицы имеют префикс `bc_`; существующие таблицы сервера не перезаписываются. Применение миграции выполняется отдельно от импорта, явным вызовом `MySqlContactDirectory::migrate()` из сервисной команды приложения.

Для подключения используются `CONTACTS_MYSQL_DSN`, `CONTACTS_MYSQL_USER`, `CONTACTS_MYSQL_PASSWORD`. Значения секретов не передавайте в аргументах командной строки и не публикуйте. Доступы задаются окружением процесса. Импорт сам не отправляет сообщения и не создаёт задания доставки.

## Excel

Обычный формат: обязательные колонки `Телефон` и `Язык`, необязательная `Почта` (также поддерживаются `phone`, `language`, `email`). Телефоны — текст в международном формате с `+`. Поддерживаются RU, EN-GB, ES, FR; `eng` нормализуется в EN-GB. Цифровые Excel-ячейки отвергаются, чтобы не угадывать утраченный код страны или округлённые цифры.

У текстового номера с уже указанным международным кодом допустимо отсутствие ведущего `+`: импорт добавляет только этот знак и показывает предупреждение `missing_plus_normalized`. Код страны и цифры не угадываются и не дописываются.

Поддерживается предоставленный формат с телефоном в B, языком в D (`язык рассылки`) и страной в E; названия компаний и имена не импортируются. Почту можно добавить шестой колонкой `Почта` или непосредственно в `manual_email` MySQL.

Формулы не вычисляются. Единственное исключение — точная запись `=+` и 7–15 цифр без операторов: она читается как буквальный телефон и отмечается предупреждением. Остальные формулы запрещены.

Строки-продолжения принимаются только по явно указанным номерам: они должны непосредственно следовать за контактом и не содержать собственного телефона, языка или почты. Так сохраняется связь строк 4–5 и 8–9 в предоставленной таблице. Обычная пустая строка игнорируется; неполная строка без явного указания вызывает ошибку. `--skip-row=N` существует для сознательного исключения строки, но для указанной таблицы не применяется.

Сначала выполните проверку (пути приведены как пример):

```powershell
php -d extension=zip -d extension=intl -d extension=fileinfo bin/import-whatsapp-contacts.php 'C:/private/contacts.xlsx' --continuation-row=5 --continuation-row=9
```

Команда выводит только количества, языки, номера проблемных строк и SHA-256 исходного файла. Телефоны, почта, имена и компании не печатаются. При любой ошибке импорт не начинается. Для применения добавьте `--apply --confirm-sha256=<хеш из проверки>`, предварительно указав окружение MySQL и применив миграцию. Хеш защищает от незаметной замены проверенного файла; повтор той же операции безопасен.

## Ручное редактирование MySQL

- `phone` — уникальный нормализованный номер E.164; изменение адреса влияет на будущие снимки.
- `whatsapp_language` — RU, EN-GB, ES или FR.
- `manual_email` — необязательная почта; пустое значение храните как NULL.
- `whatsapp_enabled`, `email_enabled` — 0/1, каналы доставки.
- `active` — общий выключатель 0/1. Импорт не включает ранее отключённого клиента обратно.
- Поля `telegram_*`, `whatsapp_registered` и ревизии изменяет приложение. Не редактируйте их вручную.

Email из одобренной Telegram-анкеты имеет приоритет над `manual_email`, язык Telegram сохраняется. Черновик или отклонённая анкета Telegram не отменяет WhatsApp импортированного клиента и не добавляет Telegram в доставку. Повторное одобрение Telegram возобновляет все доступные каналы согласно новому состоянию приложения.

Снимки `bc_snapshots`/`bc_snapshot_recipients` неизменяемы; повтор запроса с тем же ID возвращает прежние адреса и языки. Перед отдельной отправкой приложение проверяет текущее отключение. Нельзя вручную удалять служебные снимки, журнал `bc_directory_operations` или ревизии во время работы.

## Проверки

Быстрые тесты импорта: `php -d extension=intl -d extension=zip -d extension=fileinfo vendor/bin/phpunit tests/Contacts/XlsxContactsTest.php`.

MySQL-тесты используют только отдельную БД, имя которой содержит `test`: `CONTACTS_TEST_MYSQL_DSN`, `CONTACTS_TEST_MYSQL_USER`, `CONTACTS_TEST_MYSQL_PASSWORD`. Они удаляют только таблицы `bc_` внутри этой тестовой БД. Для обязательной проверки задайте `CONTACTS_REQUIRE_MYSQL_TESTS=1`; отсутствие сервера будет ошибкой, а не пропуском. Не указывайте здесь каталог с реальными контактами.

Запуск: `php -d extension=intl -d extension=zip -d extension=fileinfo -d extension=pdo_mysql vendor/bin/phpunit tests/Contacts`.
