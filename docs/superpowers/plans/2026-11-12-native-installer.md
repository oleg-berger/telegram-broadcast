# Установщик без Docker

> Implementation plan: выполнить в текущей сессии; пользователь уже одобрил добавление установщика.

**Goal:** обновить существующий Telegram-бот на Ubuntu 22.04/24.04, добавив MySQL, WhatsApp и HTTPS-вложения за 5–7 команд оператора.

**Architecture:** Python 3 из Ubuntu управляет пакетами, конфигурацией и systemd; существующие PHP-команды выполняют проверки, миграции и импорт. Нативный Go-транспорт собирается из той же закреплённой версии и патчей, что проверены в Docker. Рабочий сервер в рамках разработки не изменяется.

**Tech Stack:** Python stdlib, PHP 8.4, MySQL, systemd, Nginx, PHP-FPM, Certbot, WPPConnect Go.

**Spec:** запрос пользователя «Добавь установщик» и согласованный сценарий установки без Docker с новым WhatsApp-отправителем.

## Ограничения

- Сохранить `.env`, текущую SQLite, ключ ссылок, WhatsApp-сессию при повторном запуске; резервировать данные до миграции.
- Требуются root и уже настроенный Telegram `.env`; установщик предназначен для обновления существующего бота.
- Не запускать рассылку до отдельной команды `start`; QR подключает аккаунт оператора.
- Секреты не попадают в argv или вывод; транспорт слушает только loopback.
- Для автоматического HTTPS нужен отдельный домен с DNS на сервер, свободный от других Nginx-vhost. Существующие сайты не переписывать.

## Проверяемые риски

Повторная установка; нестандартные значения `.env`; ошибка внешней команды; уже занятый домен; сбой миграции/проверки запуска. Для каждого нужны проверки без реальных API.
