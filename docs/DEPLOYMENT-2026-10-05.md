Операторская процедура `/opt/task11-rollback.sh` (root, 0700) останавливает процессы, восстанавливает прежние исходники и окружение, возвращает прежний образ и запускает оба сервиса. По умолчанию рабочие данные сохраняются; добавочная миграция канала совместима с прежним кодом.

```bash

```

Для возврата именно к снимку перед обновлением предусмотрен отдельный вариант. Он заменяет рабочую базу и теряет изменения, появившиеся после снимка; перед его применением сохранить текущую согласованную копию и остановить приём новых действий.

```bash
bash /opt/task11-rollback.sh --restore-database
```

При резервировании сначала копируются DB и возможный WAL остановленного приложения во временный writable-каталог контейнера; SQLite backup читает эту копию и проверяет результат. Исходный Docker-том остаётся read-only. Это устраняет ошибку SQLite backup при чтении остановленной базы непосредственно из read-only-тома.
