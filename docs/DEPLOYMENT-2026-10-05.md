```bash

```

При резервировании сначала копируются DB и возможный WAL остановленного приложения во временный writable-каталог контейнера; SQLite backup читает эту копию и проверяет результат. Исходный Docker-том остаётся read-only. Это устраняет ошибку SQLite backup при чтении остановленной базы непосредственно из read-only-тома.
